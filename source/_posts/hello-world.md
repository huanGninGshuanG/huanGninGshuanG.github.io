欢迎来到你的新博客！本博客基于 **Hexo** 静态站点生成器，并使用 **[Icarus](https://github.com/PPoffice/hexo-theme-icarus)** 主题。

## 如何写文章

在站点根目录执行以下命令创建新文章：

```bash
hexo new "我的第一篇文章"
```

文章以 Markdown 格式保存在 `source/_posts/` 目录下，编辑完成后运行：

```bash
hexo clean && hexo generate && hexo deploy
```

即可重新生成并部署到 GitHub Pages。

## 主题配置

主题的配置文件为 `_config.icarus.yml`，你可以在这里修改：

- 站点头像与社交链接（`profile` 挂件）
- 代码高亮风格（`code_highlight`）
- 评论、搜索、统计等插件
